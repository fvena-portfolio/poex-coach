# Fase 5. Preguntas, alineación y decisiones

**Objetivo:** resolver las preguntas materiales que no pueden cerrarse mediante fuentes, código o pruebas.

**Entrada:** modelo actual, riesgos y preguntas pendientes.

**Acciones:**

1. Clasificar cada cuestión como hecho investigable, contradicción, decisión de producto, decisión técnica, dependencia, supuesto aceptable o asunto no relevante.
2. Investigar los hechos antes de preguntar a Francisco o al equipo.
3. Para cada decisión material, presentar hechos, incertidumbre, opciones, trade-offs, recomendación, propietario, reversibilidad, impacto y evidencia necesaria.
4. Elegir el mecanismo proporcional:
   - pregunta breve;
   - conversación;
   - pedir a Francisco que invoque `$mattpocock-skills:to-questionnaire` para varias respuestas relacionadas.
5. Solicitar intervención únicamente a los propietarios afectados.
6. Mostrar a Francisco cualquier comunicación exacta antes de crearla o enviarla.
7. Registrar decisión, propietario, fecha, fuente, alcance, razones, supuestos y condiciones de revisión.
8. Dar a cada pregunta abierta un propietario y una siguiente acción.
9. Volver a la fase afectada cuando una respuesta cambie prioridad, contexto, comprensión o modelo.
10. Si existe bloqueo, preparar una petición de ayuda con objetivo, comprobaciones, conclusión, impacto y pregunta concreta.

**Resultado:** decisiones y alineación suficientes para especificar el trabajo.

**Evidencia:** respuestas, decisiones, confirmaciones, cuestionario y preguntas abiertas con seguimiento.

**Puerta de salida:**

- `SUPERADO`: las cuestiones que pueden cambiar alcance, contratos, solución o validación están resueltas o aceptadas explícitamente.
- `REVISAR`: falta investigación, propietario, pregunta concreta o confirmación.
- `BLOQUEADO`: una respuesta o decisión externa es imprescindible.
